# Final db_bench results (2-core Xeon VM, Nov 19 2026)

Produced by `run_dbbench.sh` with the defaults (1M keys from a 10M key space,
200K operations per workload, 3 trials, medians). Raw per-run logs are not
included (they are regenerated by the script).

| Folder | LSM shape | Code |
|---|---|---|
| `A/` | default leveled compaction (3 SSTs for every filter) | final (adaptive range checks) |
| `C/` | `--disable_auto_compactions --write_buffer_size=4194304`: 36 overlapping L0 SSTs for every filter | final |
| `always-A/` | same as A | before adaptive checks (range check on every seek) |
| `B/` | leveled, 4 MB files | final; **not comparable across filters**: background compaction gave each filter a different LSM shape (26-35 SSTs) |

`seek-A.*`, `seek-C.*`, `point.*`: report figures (`report_figs.py`).
